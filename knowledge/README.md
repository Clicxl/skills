# Knowledge skills

Skills for a personal knowledge vault (PARA folders, Zettelkasten notes): capture freely, let the agent organise. Each folder holds one skill in a `SKILL.md`.

| Skill | What it does |
| --- | --- |
| `distill` | Turns the inbox's raw captures (dictation, photos, handwriting) into atomic concept notes, skill-hub log entries, media and experiment notes, and tracker issues. Then empties the inbox, commits, and reports a short digest. |
| `spar` | Socratic sparring on a vague idea or philosophy: asks, names biases, steelmans the other side, and holds its ground until you've earned your position. Saves the result as an essay in your voice. |
| `recall` | Quizzes you on a skill using only your own notes, then logs the score on the skill hub. |
| `reflect` | Monthly self-assessment from evidence: updates patterns, habits, goals and skill status, and proposes edits to your purpose note. |

All four are invoked explicitly by name.

The skills hold the procedure only. Each vault supplies its own rules in a conventions file (`CLAUDE.md` or `AGENTS.md`) at its root: folder layout, note types and templates, voice, triage, tracker and git rules. Nothing personal lives in this repo.
