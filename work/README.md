# Work skills

Skills used during my internship at FALKRAM. Each folder holds one skill in a `SKILL.md`.

| Skill | What it does |
| --- | --- |
| `create-issue` | Turns a bug, feature, task, spec, or session's work into handoff-ready issues (Problem, Suggested Fixes, Open Questions, Blockers, Done-when, Proofs), optionally grouped into epics with blockers. Publishes to GitHub, a local `.issues/` folder, or another tracker after one preview, or drafts in chat. |
| `resolve-issue` | Resolves a GitHub Issue: reads it and its parent and children, grills major decisions, plans (Opus), writes tests first, implements (Sonnet), runs tests, then hands off to a context-free review sub-agent and up to 2 Fix cycles before commits and PR. Works in Plan, Local, or Deliver mode. |
| `what-happened` | Summarises the current session as a paper-style title, a short abstract of the changes, and a results list with status, issue and PR links, and flags. Meant to be read out when asked what work was done. |

All three are invoked explicitly by name.
