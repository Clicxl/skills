# Work skills

Skills used during my internship at FALKRAM. Each folder holds one skill in a `SKILL.md`.

| Skill | What it does |
| --- | --- |
| `create-issue` | Turns a reported bug, feature, or task into a clear issue. Drafts it, or publishes it to a tracker after confirmation. |
| `resolve-issue` | Diagnoses a tracked issue, fixes and verifies it, and can prepare delivery (commits, push, PR). Works in Plan, Local, or Deliver mode. |
| `what-happened` | Summarises the current session in 4 to 5 plain sentences, plus a status line with the issue, PR, and flags. Meant to be read out when asked what work was done. |

All three are invoked explicitly by name.
